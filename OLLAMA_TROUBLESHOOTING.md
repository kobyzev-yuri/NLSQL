# Устранение проблем с Ollama

## Ошибка: "signal is aborted without reason"

Эта ошибка возникает когда запрос к Ollama прерывается из-за таймаута или проблем с соединением.

### Причины:

1. **Таймаут** - Ollama работает медленно (30-45 секунд для qwen2.5-coder:1.5b)
2. **Ollama не запущен** - сервис недоступен на порту 11434
3. **Модель не загружена** - модель qwen не найдена в Ollama

### Решения:

#### 1. Проверка Ollama

```bash
# Проверить, что Ollama запущен
curl http://localhost:11434/api/tags

# Если не отвечает, запустить Ollama
ollama serve
```

#### 2. Проверка модели

```bash
# Проверить доступные модели
ollama list | grep qwen

# Если модель отсутствует, загрузить
ollama pull qwen2.5-coder:1.5b
```

#### 3. Использование более быстрой модели

В `config.env` установите:
```env
OLLAMA_MODEL=qwen2.5-coder:1.5b  # Самая быстрая (986 MB)
```

Или попробуйте другие модели:
- `qwen2.5:1.5b` - альтернатива (986 MB)
- `qwen3:8b` - более мощная, но медленная (5.2 GB)

#### 4. Упрощение запросов

Для Ollama используйте более простые запросы:
- ✅ "Покажи всех пользователей"
- ✅ "Список отделов"
- ❌ Избегайте сложных запросов с множеством JOIN и подзапросов

#### 5. Переключение на GPT-4o

Если Ollama не работает стабильно, переключитесь на GPT-4o:
- В веб-интерфейсе выберите "GPT-4o (OpenAI/ProxyAPI)"
- Или в `config.env`: `LLM_PROVIDER=openai`

### Увеличение таймаута

Таймаут для Ollama уже увеличен до 120 секунд в интерфейсе. Если этого недостаточно:

1. В `src/simple_web_interface.py` найдите строку:
   ```javascript
   const timeout = llm_provider === 'ollama' ? 120000 : 90000;
   ```
2. Увеличьте значение (в миллисекундах)

### Логи для диагностики

```bash
# Логи Core API
tail -f logs/core_api_8000.out | grep -i ollama

# Логи Simple UI
tail -f logs/simple_ui_3000.out

# Проверка работы Ollama напрямую
curl -X POST http://localhost:11434/api/chat \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen2.5-coder:1.5b",
    "messages": [{"role": "user", "content": "SELECT * FROM users"}],
    "stream": false
  }'
```

### Рекомендации

1. **Для разработки:** Используйте `qwen2.5-coder:1.5b` - быстрая и легкая
2. **Для продакшена:** Рассмотрите `qwen3:8b` для лучшего качества (но медленнее)
3. **Для быстрого тестирования:** Используйте GPT-4o
