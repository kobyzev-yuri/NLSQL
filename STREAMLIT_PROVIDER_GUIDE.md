# Руководство по использованию переключателя провайдера в Streamlit (8501)

## Как переключаться между Ollama и GPT

### В интерфейсе Streamlit (http://localhost:8501)

1. **Откройте интерфейс** в браузере
2. **Найдите выпадающий список "🤖 LLM Провайдер"** в верхней части формы
3. **Выберите нужный провайдер:**
   - **GPT-4o (OpenAI/ProxyAPI)** - быстрая генерация (~2-5 сек)
   - **Qwen (Ollama локально)** - локальная генерация (~30-45 сек)

4. **Визуальная индикация:**
   - Под выпадающим списком появится информационное сообщение о выбранном провайдере
   - При успешной генерации SQL будет показано, какой провайдер использовался

5. **Введите вопрос** и нажмите "🔍 Генерировать SQL"

### Что показывает интерфейс

- **Вверху страницы:** Информация о провайдере по умолчанию из `config.env`
- **Под выпадающим списком:** Индикация выбранного провайдера для текущего запроса
- **После генерации:** Подтверждение, какой провайдер был использован

### Проверка работы

1. Выберите "GPT-4o" → Введите простой вопрос → Должно работать быстро (~2-5 сек)
2. Выберите "Qwen (Ollama)" → Введите тот же вопрос → Будет работать медленнее (~30-45 сек)

### Устранение проблем

**Если Ollama не работает:**
- Проверьте, что Ollama запущен: `curl http://localhost:11434/api/tags`
- Проверьте, что модель загружена: `ollama list | grep qwen`
- Если модель отсутствует: `ollama pull qwen2.5-coder:1.5b`

**Если таймаут:**
- Для Ollama таймаут увеличен до 120 секунд
- Если все еще таймаут, попробуйте более простой запрос или переключитесь на GPT-4o

**Если ошибка соединения:**
- Убедитесь, что Simple UI (порт 3000) запущен: `curl http://localhost:3000/`
- Перезапустите сервисы: `./run_stack.sh restart`

## Отличие от config.env

- **config.env** - устанавливает провайдер по умолчанию для всех запросов
- **Переключатель в интерфейсе** - переопределяет провайдер только для текущего запроса

Это позволяет быстро тестировать оба провайдера без изменения конфигурации!
