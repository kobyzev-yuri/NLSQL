# Загрузка документации из DocStructureSchema

Скрипт `src/tools/load_docstructure_schema.py` автоматически анализирует JSON файлы из директории `data/DocStructureSchema` и загружает структурированную документацию в векторную базу знаний.

## Что делает скрипт

1. **Анализирует JSON файлы:**
   - `EQDocTypes.json` - типы документов и связанные таблицы
   - `EQCategories.json` - категории документов
   - `EQDocStates.json` - состояния документов

2. **Извлекает информацию:**
   - Названия таблиц и их назначение
   - Типы документов для каждой таблицы
   - Категории и их описания
   - Состояния документов

3. **Создает документацию:**
   - Общий обзор системы
   - Бизнес-логика и связи между таблицами
   - Детальная документация по каждой таблице

4. **Загружает в векторную базу:**
   - Использует `KBTrainingClient` для загрузки через API
   - Разбивает на батчи для оптимизации
   - Добавляет метаданные и теги

## Использование

### Предварительные требования

1. **Запустите Core API:**
   ```bash
   ./run_stack.sh start core_api
   ```

2. **Проверьте доступность API:**
   ```bash
   curl http://localhost:8000/health
   ```

### Запуск скрипта

```bash
python src/tools/load_docstructure_schema.py
```

### После загрузки

Сгенерируйте эмбеддинги для загруженной документации:

```bash
python -m src.tools.generate_embeddings_hf \
  --dsn "$DATABASE_URL" \
  --model "$HF_MODEL_NAME"
```

## Формат загружаемых документов

Каждый документ содержит:

- **content**: Структурированная документация в формате Markdown
- **content_type**: `documentation`
- **metadata**:
  - `source`: `DocStructureSchema`
  - `filename`: Имя исходного файла или сгенерированное имя
  - `type`: Тип документации (`overview`, `business_logic`, `table_documentation`)
  - `table_name`: (для таблиц) Имя таблицы

## Примеры создаваемой документации

### Обзор системы
```markdown
# Система DocStructureSchema - Обзор

Система управления документами и пользователями...

## Основные категории и таблицы:

### Справочники
- **tbl_currencies**: Валюта
- **tbl_countries**: Список стран
...
```

### Документация таблицы
```markdown
## Таблица: tbl_business_unit

### Типы документов:
- Профиль клиента

### Категории:
- Профиль: Профили клиентов системы

### Описание:
- Профиль клиента
```

## Настройка

Путь к директории с данными настраивается через переменную окружения:

```bash
export DOCSTRUCTURE_DIR=data/DocStructureSchema
```

Или в файле `config.env`:
```
DOCSTRUCTURE_DIR=data/DocStructureSchema
```

## Устранение проблем

### API недоступен
```
❌ Ошибка: Core API недоступен на http://localhost:8000
```
**Решение:** Запустите Core API: `./run_stack.sh start core_api`

### Директория не найдена
```
❌ Ошибка: Директория data/DocStructureSchema не найдена
```
**Решение:** Проверьте путь в `config.env` или укажите правильный путь через переменную окружения

### Ошибки загрузки
Если некоторые документы не загрузились, проверьте логи и убедитесь, что:
- API работает корректно
- База данных доступна
- Есть права на запись в таблицу `vanna_vectors`
