## Принципы очистки

1. **Не ломать функционал**: Fallback методы оставляем до появления API
2. **Документация в приоритете**: Сначала обновляем документацию, потом код
3. **Постепенная миграция**: Не удаляем старые методы сразу, помечаем как legacy
4. **Обратная совместимость**: Старые скрипты должны продолжать работать
