


Здесь приведено описание и смысл наиболее часто используемых таблиц проекта Tradeco. Это не все таблицы, но те, которые наиболее важны для понимания общих принципов работы системы.


1.Системные таблицы.

Все таблицы имеют обязательные поля:
id - уникальный идентификатор;
deleted - равен true, если запись удалена, и false для существующих записей;
creationdatetime - дата и время создания записи;

equsers - таблица пользователей. Таблица имеет следующие поля данных пользователя: 
surname, firstname и patronymic - соответственно фамилия, имя и отчество.
login - логин для входа
phone и email - номер телефона и адрес электронной почты
inn - ИНН.

eq_accesses_roles - таблица прав доступа к контроллерам и их методам, дочерняя таблица для eqroles. 
Поле role_id - идентификатор роли (id записи в таблице ролей), которой принадлежит право.

eqRoles - таблица ролей (роль это сущность, включающая набор прав доступа). 
Роль имеет название (поле rolename) и код (поле role_code)

eqgroups - таблица групп пользователей (группа пользователей характеризуется набором ролей). 
Группа имеет название (поле groupname)

eqgroupsroles - таблица связей между группами пользователей и ролями. Определяет, какие роли имеют члены группы. 
Поле groupid - идентификатор группы, roleid - идентификатор роли.

eqgroupmembers - таблица членов групп, определяет какие пользователи входят в какие группы. 
Поле groupid - идентификатор группы, 
поле userorgroupid - идентификатор входящего в группу пользователя, или подгруппы.

eqcategories - таблица категорий документов (категория - набор типов документов, объединенных по общему функционалу). 
Поле categoryname - наименование категории.

eqdoctypes - таблица типов документов. 
Поле category - категория, к которой относится данный тип документа,  
doctype - наименование типа документа, 
tablename - таблица, в которой хранятся документы типа.

eqspecifications - таблица спецификаций, или внутренних таблиц для типов документов (например для организации это может быть список сотрудников в организации). 
Поле doctypeid - идентификатор типа документа, 
tablename - имя таблицы.

eqdocstructure - таблица структуры типов документов - набор параметров (полей таблицы) типа документа для самого документа или спецификации. 
Поле doctypeid - идентификатор типа документа, 
tablename - наименование таблицы, 
fieldname - наименование поля в таблице, 
fieldnamedisplay - пользовательское название поля.

eqview - таблица представлений, каждое представление определяет документ, набор полей документа, их внешний вид и наименование, которые видит пользователь на странице. 
Поле viewname - наименование представления.

eqdocstates - таблица статусов документов. Каждый документ характеризуется текущим статусом в соответствии с бизнес-логикой проекта и может переходить из одного статуса в другой.
Поле statename - наименование статуса,
statedescription - код статуса, 
docid - документ, к которому относится статус.




2.Таблицы документов бизнес-логики.

Все таблицы имеют обязательные поля:
id - уникальный идентификатор;
deleted - равен true, если запись удалена, и false для существующих записей;
creationdatetime - дата и время создания документа;
owner_id - идентификатор пользователя (id записи в таблице equsers), которому принадлежит документ;


tbl_business_unit - таблица профилей зарегистрированных организаций или ИП (таблица профилей). Относится к типу документа "Профиль клиента". Характеризуется статусом профиля (поле statusid, указывающее на запись в таблице статусов eqdocstates). Статус профиля изменяется в процессе работы с данным профилем. Таблица имеет поля, ссылающиеся на другие таблицы:
bik - идентификатор записи в таблице банковских идентификационных кодов tbl_bik;
agreement_tariff - идентификатор записи в таблице тарифов tbl_tariff;
edo_type - идентификатор записи в таблице типов ЭДО tbl_edo_type;
sales_channel - идентификатор записи в таблице каналов продаж tbl_sales_channel;
personal_manager - идентификатор записи в таблице пользователей equsers;
sales_segment - идентификатор записи в таблице сегментов продаж tbl_sales_segment;
contract_version - идентификатор записи в таблице типов контрактов tbl_contract_versions;
regions_operation - идентификатор записи в таблице регионов операционной дейтельности tbl_regions_operation;
country - идентификатор записи в таблице стран tbl_countries;

Другие значимые поля:
name - наименование организации (ИП);
legal_address - юридический адрес организации (ИП);
inn - индивидуальный налоговый номер (ИНН);
kpp - код постановки на учет (КПП);
bank_name - наименование банка;
bik - банковский идентификационный код;
revenue_amount - размер выручки;

Документ профиля имеет дочерние таблицы спецификаций: 
tbl_business_unit_agreements - таблица соглашений, поле docid - идентификатор (id) профиля;
tbl_business_unit_comment- таблица комментариев к профилю, поле docid - идентификатор (id) профиля;
tbl_business_unit_contacts - таблица контактов профиля (контактных лиц), поле docid - идентификатор (id) профиля;
tbl_business_unit_docs - таблица документов профиля, поле docid - идентификатор (id) профиля;
tbl_business_unit_signatories - таблица подписантов, поле docid - идентификатор (id) профиля;








tbl_principal_assignment - таблица поручений. Относится к типу документа "Поручение Принципала для оплаты к Агентскому договору". Характеризуется статусом поручения (поле statusid, указывающее на запись в таблице статусов eqdocstates). Статус поручения изменяется в процессе работы с данным поручением. Таблица имеет поля, ссылающиеся на другие таблицы:
signatory - идентификатор записи в таблице подписантов tbl_business_unit_signatories;
product_category - идентификатор записи в таблице категорий продуктов tbl_product_categories
personal_manager - идентификатор записи в таблице пользователей equsers;
payment_status - идентификатор записи в таблице статусов платежей tbl_payment_statuses;
company_payer - идентификатор записи в таблице плательщиков tbl_payers_short;
subagent_id - идентификатор записи в таблице субагентов tbl_subagent;
type_assignment - идентификатор записи в таблице типов поручений tbl_assignment_types;
client_manager - идентификатор записи в таблице пользователей equsers;
designated_agent - идентификатор записи в таблице пользователей equsers; 
sales_segment - идентификатор записи в таблице сегментов продаж tbl_sales_segment;
sales_channel - идентификатор записи в таблице каналов продаж tbl_sales_segment;
postpayment_type_id - идентификатор записи в таблице типов постоплаты tbl_postpayment_types;
settlement_type - идентификатор записи в таблице типов взаиморасчётов tbl_settlement_types;
agreement_id - идентификатор записи в таблице соглашений tbl_business_unit_agreements;

Другие значимые поля:
reg_number - регистрационный номер;
contract_date - дата контракта;
agent_income - доход агента;
agent_revenue - прибыль агента;
bank_name - наименование банка;
iban -  международный номер банковского счёта;
currency - валюта для расчетов по контракту;
total_sum - общая сумма контракта (0 - если контракт еще не подписан);
payment_count_in_rub - сумма платежа по поручению в рублях;
subagent_income - доход субагента;
fligh_date - дата отпраки поручения в рейс;

Документ поручения имеет дочерние таблицы спецификаций: 
tbl_principal_assignment_addedo - таблица ЭДО, поле docid - идентификатор (id) поручения;
tbl_principal_assignment_assigmentcontract - таблица контрактов, поле docid - идентификатор (id) поручения;
tbl_principal_assignment_comment - таблица комментариев, поле docid - идентификатор (id) поручения;
tbl_principal_assignment_docs - таблица документов, привязанных к поручению, поле docid - идентификатор (id) поручения;
tbl_principal_assignment_invoices - таблица инвойсов, поле docid - идентификатор (id) поручения;
tbl_principal_assignment_reports - таблица отчетов, поле docid - идентификатор (id) поручения;
tbl_principal_assignment_verif_add_docs - таблица дополнительных файлов, поле docid - идентификатор (id) поручения;



tbl_assignment_types - таблица типов поручений, 
поле name - наименование типа поручения;



tbl_contract_types - таблица типов контрактов,
поле name - наименование типа контракта;



tbl_countries - таблица стран,
поля name, full_name - наименование и полное наименование страны;
alpha_2, alpha_3 - коды страны;



tbl_currencies - таблица валют,
поле lettercode - код валюты;
поле currname - наименование валюты;



tbl_incoming_payments - таблица входящих платежей,
поле principal_assignment_id - идентификатор поручения (поле id в таблице tbl_principal_assignment), к которому относится платеж;
поле payment_date - дата платежа;
поле credit - сумма платежа;
has_nds - включен ли НДС;
bank_name - наименование банка;



tbl_natural_monopolies - таблица организаций - естественных монополий,
поле inn - ИНН организации;
поле kpp - КПП организации;



tbl_payers_short - таблица плательщиков,
поле payer_bank - банк плательщика;
поле payer_name - наименование плательщика;
поле country_name - страна плательщика;



tbl_payment_statuses - таблица статусов платежей,
поле name - наименование статуса;
поле status_code - код статуса;


tbl_sales_channel - таблица каналов продаж,
поле name - наименование канала продаж;
поле code - код канала продаж;


tbl_sales_segment - таблица сегментов продаж,
поле name - наименование сегмента продаж;


tbl_settlement_types - таблица типов взаиморасчетов,
поле name - наименование типа;
поле code - код типа;


tbl_subagent - таблица субагентов,
поля subagent_en и subagent_ru - английское и русское наименование организации - субагента;
поле inn - ИНН организации - субагента;


tbl_treasurys - таблица казначейств,
поле code - код казначейства;
name - страна казначейства;
description - описание казначейства;
